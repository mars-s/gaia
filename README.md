# Gaia

Open-source, self-hosted agent that grows its own UI and tools. Built on Pi Durable.

Gaia starts as a single chat box. You sign in with your Claude or ChatGPT plan, it asks how you work, then it builds its own interface, tools, agents and clients around you, changing its own code safely with staged checks and automatic rollback.

**Status:** local Board UI chat seed implemented. Safe self-modification is in progress. See [SPEC.md](SPEC.md) (locked v1.2), [local development](docs/local-development.md) and [hosting](docs/hosting.md).
